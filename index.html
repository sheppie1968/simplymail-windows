SimplyMail for Windows

Email, calendar, contacts and tasks for your own IMAP and POP3 accounts. Version 1.0.20, for 64-bit Windows 10 and Windows 11.

Download

SimplyMail-1.0.20.msi (82 MB)

Install

Open the downloaded file. SimplyMail installs for you alone, so it doesn't ask for an administrator's password, and adds itself to the Start menu.

The installer isn't signed yet, so Windows may say it protected your PC. Choose More info, then Run anyway.

Updates

SimplyMail doesn't update itself on Windows. To update, download the newest version from this page and open it: it replaces the old version and keeps your accounts and settings.
